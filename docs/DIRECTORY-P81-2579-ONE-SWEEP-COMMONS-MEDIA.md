# P81: worldwide Directory original-site Commons source search — ONE campaign

P80 completed the 2,579 CL2 physical-anchor index across 76 countries and retrieved 44,777 raw Wikidata P18 image-source records. Its 1,020 name-only lead links across 492 anchors are not enough for a meaningful worldwide photography review. P80 source errors (BR, IN, MX) and capped countries (AT, CZ, DE, ES, FR, GB, IT, PL, RU, SE, US) remain explicit holds, not zero results.

P81's **single user-facing discovery campaign** examines every one of the existing 2,579 CL2 physical anchor IDs with bounded Wikimedia Commons File-namespace source searches. The 11 pre-existing CL2 shards are machine transport only, max three parallel workers; no human reviews between them. Each source hit preserves the exact Commons page ID, original SHA1 metadata claim, licensed-source *claim*, author claim, preview URL, size, file title and relation to a single immutable anchor ID. No source is treated as a verified exact building match simply because words overlap.

All 2,579 anchor results, including no distinctive building names, query failures, and no candidate files, must be present in a single consolidated research export. A human image review is staged **only after** worldwide source discovery and the visual-preview acquisition pass have materially completed, using several hundred photographs in one interface. Never mix one venue name with another church's photography without source evidence.

No Google Maps scraping, paid APIs, extra map pins, image publication, false rights permissions, or regeneration of the existing Directory master. Research-only imagery at zero cost. P81 source metadata is not an original-byte download or a publication approval.

P80's 44,777 source rows should remain separately archived with its artifact SHA256; the P80 completion audit has been committed to main. P81 is complementary Commons title/metadata research for sites not matched by broad country Wikidata discovery.
