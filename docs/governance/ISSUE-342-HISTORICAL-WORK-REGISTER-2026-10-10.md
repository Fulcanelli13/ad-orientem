## Status vocabulary and acceptance gate

- **IMPLEMENTED** — content/code is present on current `main` with a canonical owner, regression test, appropriate source support and verified user-facing behaviour.
- **IMPLEMENTED_HIDDEN** — on `main` but intentionally not exposed; requires an explicit exposure/retirement decision.
- **PARTIAL** — some research/content/code integrated; list outstanding records and tests.
- **READY_TO_IMPLEMENT** — accepted authored content exists, but production ingestion/UI is not complete.
- **SOURCE_HOLD** — missing exact primary text, donor evidence or sufficient source verification; do not invent or publish.
- **RESEARCH_ONLY** — preserved discovery/analysis not yet accepted or mapped.
- **SUPERSEDED / REJECTED** — deliberate disposition with exact replacement/grounds, not silent deletion.

Every accepted record requires a traceable **research source → canonical SOT/owner → production path & commit → automated validation → phone/user-facing acceptance** chain, or an explicitly documented hold/rejection.
