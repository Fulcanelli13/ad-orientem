## Existing owner and publish workflow

The next step should not be a seventh Weiser source-discovery wave. Batch-review the 42 P1 drafts together, alongside the earlier 12 selected-source EN/FR editorial drafts. **These are 54 editorial records, not 54 distinct customs.**

1. **Owner parity first.** Reconcile every source-backed draft against existing canonical Customs Atlas, Calendar, Saints, Pray, Explore and Mass Special Days entries. Enrich existing owners where possible instead of minting new customs.

5. **No cost or outreach.** Continue using public sources and the existing repository only; no vendor/contact/integration spending is assumed.
