## Corrective pass 1 implemented in branch

1. Introduce a dedicated bounded historical-witness resolver in `src/pray/litany-source.js` (no second devotional engine).
2. Switch English lookup to the named 1883 source, French lookup to the original 1862 Corneille page. Keep edition explicitly `UNCOLLATED`.
3. Refuse to import the following Psalm/collects if the Litany end boundary is absent. Do not silently generate or truncate a replacement.
4. Replace invented semantic subheadings by honest numbered reading partitions.
5. Link original historical transcription in the source drawer, with transparent edition status.
6. Add retry for remote failures and invalidate a previous language's text upon EN/FR preference changes.
7. Add repeatable checks to `tests/pray-presentation.mjs`. CI and actual browser source loading are mandatory merge gates.
