# Atlas cinematic acceptance follow-up — map-first and free-pan

After PR #1235 published the `?atlasCinema=1` review, examination of the 320px, 390px, and 768px screenshot artifacts showed a UX defect: it opened at Creation (canonical index 0), which cannot be geolocated, resulting in a blank map region. This PR switches **only the opt-in review mode** to its **earliest source-qualified geographic scene**. It derives the index from `buildBibleAtlas()` output, not a fabricated coordinate or hardcoded story index. Creation remains canonically first and is directly reachable through the Beginnings shortcut. The ordinary/default Atlas still opens at index 0.

A deterministic Chromium acceptance test mounts a lightweight instrumented MapLibre-compatible adapter via the existing `AO_FIND_MAPLIBRE_MODULE` seam. It simulates real browser pointer movement over the map canvas, verifies the emitted `dragstart` disables Follow, and ensures the timeline *still updates map-pin GeoJSON but does not move the camera*. Pressing Follow must recenter the exact selected qualified stop. The test also reopens Creation without inventing a pin. This is a **real DOM/pointer integration test with a mocked MapLibre engine**, not a certification of external tile/map infrastructure or handset haptics.

The refreshed live MapLibre screenshot also exposed visible modern geopolitical boundaries and city/country labels, at odds with the review’s historical visual language. This opt-in PR now hides base-map symbol labels and explicitly classified administrative/road lines after MapLibre style load; it **never suppresses the application's source-backed point layers or land/water geography**. This is a cosmetic modern-label suppression, **not** a historically reconstructed coastline or evidence-qualified ancient road map. Exact period cartography and art direction remain separate decisions.

The separate Playwright review test captures 320/390/768 screenshots using the deployed MapLibre path. A passing deterministic test and renewed screenshots improve confidence but do not replace manual testing on an actual phone, which remains an explicit review gate. Full 151-event chronology, source location qualifications, real Scripture-reader link, #1069 research hold and sacred-art review ownership are unchanged.
