### Mandatory correction to the research workflow

1. **Never use a city/region/mission label as photographic evidence of a specific worship venue.** A source saying `Gothenburg` or `Misión Durango` may name a city, not the actual building.
2. **Validate each physical site independently:** exact place ID/address, alternate names, affiliation, coordinates where sourced, official-site or building-specific image evidence, and source-to-site crosswalk.
3. **Visually inspect actual image content** for wrong subject, unsuitable building, unrelated civic/transport/scenic imagery, frames, illustrations and inappropriate hero composition. Source metadata and image hashes are not visual subject understanding.
4. For apparently relevant church/altar/interior photos, **verify the building separately**; low-resolution contact sheets are only a preliminary visual rejection pass. The 305 outstanding sources are **not approved**.
5. Keep exact P83–P87 source IDs and rights claims, but do not ask the user to editorially approve the original 385-image pack. Do not auto release or publish the sources.
6. Do not create another duplicate editorial gallery; future work should enrich the current indexed research ledger and the existing approved-place media/gallery registries only after their independent publication gates pass.
