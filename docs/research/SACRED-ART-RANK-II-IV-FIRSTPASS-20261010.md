# Rank II–IV accelerated source artwork pass

10 October 2026, Issue #885 / PR #887.

The Class-I-first sequencing restriction is suspended for research. All 312 observed 2026 Class II/III/IV dates are included in the new automated proposal register.

The workflow now generates one source-hashed existing museum CC0 original per day, assigning either a conservatively identified named event/person, a Marian Saturday association, a year-specific liturgical season association, or a universal painting where no stronger evidence exists. These are contextual illustration proposals, NOT exact feast or Gospel coverage. Detailed source gaps are exported per date in CI so further acquisition can be batched by repeated subject.

Existing Class I A/B/C ledgers are unchanged. Zero human image, crop or production approvals, no physical duplicates, no app runtime changes. The final human-selection HTML is still separate.
