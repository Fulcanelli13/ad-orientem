## Handoff acceptance

1. Resolve title/artist match to **specific physical object accession** and prove identical depicted work against the curator-reviewed photo, not merely similar iconography.
2. Reuse an already approved painting across calendar dates only with a specifically typed liturgical relationship: appointed Gospel, feast iconography, season or devotional context. No generic season image counts as an exact Gospel illustration.
3. Determine independently reusable actual **photographic reproduction**; no Prado media or mirrors, no copyright-uncertain commercial photographs, no paid licences or permission requests.
4. Test uncropped artwork on a handset, create derivative only after approval, record SHA/credits/licence and production asset path; no crops cutting key figures.
5. Promote each record separately after confirmed selection and release gates. **Publication-certified count remains zero.**
