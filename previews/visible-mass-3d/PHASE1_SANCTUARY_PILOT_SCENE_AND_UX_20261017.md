## Phase 1 object-card interaction contract

1. **Church first:** show the authentic photo or panorama. Default screen has no floating glossary grid, data dump, help tutorial or bright progress gamification. A restrained discovery cue highlights only an actually visible, editor-mapped parent object.
2. **Tap a visible parent:** persistent location/title from the actual scene (e.g. *High altar*). Card shows canonical EN/FR/LA label if available, the existing source-backed short definition read from G404, and a compact group of **2–4 high-value questions**. Do not repeat the entire longer glossary article in the collapsed card.
3. **Open one question:** show the verified answer *after* Phase 1.5; today the question exists only as an indexed research prompt. Offer optional history/rubrics/symbolism tiers only when independently supported. No fabricated explanatory text.
4. **Inspect further:** show subobjects only if their existence is visible in a closer photograph or a separate source-labelled inspection view. If a tiny item is absent, the user may explore it from a labelled list or parent card without a misleading hotspot.
5. **Preserve return state:** close question → return to parent card; close card → return to the same photograph, original yaw/pitch/zoom/scroll and focus. Avoid auto-reset and new browser tab for internal canonical reading.
6. **Languages and authority:** original glossary entry remains the owner; read its bilingual definition rather than inserting snapshots into a second app. Question-bank EN text is an editorial seed; translate/review separately for FR. Latin is only used for accurate technical labels. 1962 vs contemporary usage must be explicit.
7. **Phase 2 handoff:** an associated Mass moment, priestly action, ceremonial variation or prayer is a *metadata link* to source-owned MF/Guide/Mass cues, never a separate animation or new ceremonial doctrine in Phase 1. In particular, preserve the LIVE reader source/card mapping and pre-Mass Proper logic.

## Canonical answer and source-owner safety

- The registry references **existing glossary G IDs**, not 30 newly minted duplicate concepts. A G### concept link marked *related* is **not** a fully answered distinct object entry; nine of the 30 remain related, one (EQ06 altar bell) lacks an exact glossary match.
- Some existing source-backed canonical definitions are **current-law framed**, including G079 Altar (1983 Code canons 1235–1239) and G080 Tabernacle (1983 Code canons 938–940). Those descriptions remain valid source-owned background but **cannot by themselves certify precise 1962 rubrics**. Phase 1.5 must bring in the proper historical/1962 sources before presenting rubrical claims. Do not silently re-label source authority.
- New prompts about six versus seven candles, beeswax, altar stones, altar-card text, historical rail development and purification practice require independent source review. A related glossary definition or source link is not evidence that the proposed detailed answer is already approved.
- The separate P0 Ultra Master source bridge remains a **draft** with its existing source/cue certification limits. Mass Formation P1 and original LIVE/Simple/Missal readers are not altered by this research file.
