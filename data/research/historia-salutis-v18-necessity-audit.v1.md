# Historia Salutis — v18 narrative-necessity audit

**Editorial proposal · 17 October 2026 · Not approved for production**

## Governing distinction

Historia Salutis is **one continuous history of salvation**, not an exhaustive anthology of biblical stories. The canonical Bible, the original 151 event identities, the existing person/genealogy/Atlas navigation and the original 78-chapter/217-source-segment workbook remain intact. This editorial audit proposes which Scripture segments contribute to the compulsory storyline. It **does not** create a second extended biblical experience, alter the Bible reader, add character pages, or remove canonical Scripture.

- **A — Essential**: decisive covenant, lineage, messianic, Redemption, Church or consummation beat in the main narrative. A does *not* demand a standalone chapter.
- **B — Brief context**: supply the minimal causal transition inside the continuous narrative or existing distinct genealogy navigation.
- **C — Independent story**: not compulsory. Can appear **only through existing** character, Atlas event or Bible reference destinations once verified; no new presentation is required.
- **D — No separate featured placement**: duplicated editorial material or repeated retelling; retain canonical Bible source and relevant existing cross-references.

**Numbers are proposed editorial classifications, not theological grades or source-popularity votes.** A unit may be beloved, frequently featured or indispensable to Catholic biblical knowledge while not necessary in this particular continuous narrative.

A candidate match is not permission to route into a new or unbuilt experience. The **Philippi jail episode (H73-02)**, and all five detailed Deborah/Gideon/Samson segments (H27), lack an exact existing Atlas event. Their fallback is their canonical Bible reference, with a person link only if an actual existing Paul/Judges person view is separately verified. **The C classification removes mandatory narration; it does not require creating any featured story at all.**

Esther's nominal source reference requires the pre-existing Catholic Esther edition concordance before deep linking. Existing donor story-group classifications remain research-only, never equivalent to live user-facing character biographies.

## Editorial gates before changing the main reader

1. Review **every C** against already-existing person, event and Scripture destinations. If no real record exists, retain the Scripture reference, **do not invent** a new character module or secondary story collection.
2. Review **every B** as a possible one- or two-sentence context link or a cross-reference. It is not automatically its own reading.
3. Review **every A** for narrative necessity, Catholic doctrinal accuracy, genealogy continuity and prior source-edition/rights holds.
4. Only after the user accepts dispositions, decide where neighboring main-story beats should be merged. The original 78 chapters and 217 source coordinates are stable research identifiers, **not a required public table of contents**.
5. Reconcile the current 40-unit high-risk correction overlay and the original v18 workbook before producing final narrated text. No PR is publication-ready by virtue of this analysis.
