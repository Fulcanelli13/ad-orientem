The owner-supplied 65-scene original HTML and 65 icon files are preserved byte-for-byte. `ao-sanctuary-embedded.js` is an adapter; the original 3-D geometry, figures, camera, lighting and keyframes are not edited. Enable only with the host preview flag `aoSanctuaryPreview=1`.

The inherited original C11 scene already has S standing on the Epistle side but without a book. **The native curated 65-card reader does not expose a focusable C0075 paragraph cue.** The browser acceptance caught this; do not forge a source cue. Leaving the C11 card removes the prop. No new source texts, cues, or actors are created.
- **C13 Missal transfer**: Ritus servandus VI.5 and the research registry's **MR62.SOL.B02.004** explicitly place the **subdeacon's Missal transfer to the Gospel side** before the Solemn Gospel. At the exact native C0081 focus, the adapter now places the existing subdeacon **statically** beside the already transferred Missal, without duplicating the book or playing Claude's original server-carry animation. This resolves the **Solemn actor assignment / destination pose only**. C0080, C0082, a wrong macro, MISSAL or choir focus must never start a transfer.

The original C57 still-stage already places the priest and ministers at the rail; the adapter now returns `AT_RAIL_STATIC` for the real `AO.CARD.025` source card, with **no invented C57 walking animation**. Solemn form-state `SMIN-014` (recovered source certification) says the **deacon holds the Communion paten**. At C57 in Solemn Mass, the existing deacon sprite now has a small **adapter-only static paten plate** attached to his original billboard; it is removed on C58, wrong macro, Low/Sung form switch, Asperges or LIVE→MISSAL clear.
