# Assets

Ad Orientem visual assets have explicit semantic ownership.

- `assets/active/` contains the externalized production subset of the authoritative frozen bank.
- `assets/inventory/` contains the V4/V4.1.1 semantic contract, provenance and QA metadata.
- Historical artwork is not authoritative merely because it still exists elsewhere in the repository.

Preserve provenance and canonical semantic ownership. Do not replace approved artwork merely to simplify file handling, and do not use legacy assets to fill canonical semantic roles by filename guesswork.

See `assets/inventory/README.md` for the authority rules.
